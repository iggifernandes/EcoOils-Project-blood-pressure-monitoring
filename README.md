# EcoOils Mentari — Blood Pressure Monitoring

Static web app (GitHub Pages). Logs daily health check-ups to the shared Google Sheet ("BloodPressure" tab) through the Apps Script web app set in `SHEETS_WEBHOOK_URL` inside `index.html`.

Files: `index.html`, `personnel-lists.js`, `combobox.css` — keep them in the same folder.

`personnel-lists.js` and `combobox.css` are duplicated in the Alcohol repo. Change a master list in one place, change it in the other.
